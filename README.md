# AI 사진 탐정

원본 사진과 AI 보정·AI 생성 사진을 가려내는 수업용 게임입니다. GitHub Pages로 올리면 QR로 접속해 휴대폰 홈 화면에 설치하고, 이후 인터넷 없이 실행할 수 있습니다.

- `index.html` 앱 본체 · `pack.js` 원본 vs AI 보정 30쌍 · `gen.js` AI 생성 사진 60장
- `install-guide.html` 설치·운영 안내 · `photo-guide.html` 사진 가이드

원본 사진 출처: Wikimedia Commons (작가·라이선스는 앱 안에 표시). AI 생성 사진: Gemini, ChatGPT.
